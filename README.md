## Projects

### [Sentio](https://github.com/HarshitS17/sentio)

Real-time stock sentiment pipeline built around Kafka, WebFlux, and Redis.

Scrapes financial news, scores headlines, and streams per-ticker sentiment to a live dashboard.

`Java` `Spring WebFlux` `Kafka` `Redis` `Docker`

### [Latensys](https://github.com/HarshitS17/latensys)

API monitoring and rate-limiting service.

Tracks P95 latency, stores metrics in PostgreSQL, and uses Redis to control request rates.

`Java` `Spring Boot` `PostgreSQL` `Redis`

### [Riffly](https://github.com/HarshitS17/Riffly)

Self-hosted music streaming server for a local library.

Includes JWT authentication, playlists, and seekable audio streaming.

`Java` `Spring Boot` `Spring Security` `PostgreSQL`

### [Braillify](https://github.com/HarshitS17/Braillify)

Converts scanned textbook diagrams into embossable tactile graphics with Braille labels.

Built around a Python processing pipeline with a React frontend.

`Python` `FastAPI` `React` `TypeScript`
