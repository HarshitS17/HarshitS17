## Projects

### [Sentio](https://github.com/HarshitS17/sentio)
Real-time stock sentiment using Kafka, WebFlux and Redis.

Scrapes finance news, scores each headline with VADER, and streams per-ticker sentiment to a live dashboard over SSE. Each stage runs on its own and talks to the others through Kafka.

`Java` `Spring WebFlux` `Kafka` `Redis` `Docker`

### [Latensys](https://github.com/HarshitS17/latensys)
API monitoring with P95 latency tracking and Redis rate limiting.

Made to see how an API behaves under load and to keep heavy callers from taking it down.

`Java` `Spring Boot` `PostgreSQL` `Redis`

### [Riffly](https://github.com/HarshitS17/Riffly)
A self-hosted music streaming server.

Streams your local library with seekable playback, JWT login and playlists.

`Java` `Spring Boot` `Spring Security` `PostgreSQL`

### [Code-Extractor](https://github.com/HarshitS17/Code-Extractor)
Pulls code snippets out of YouTube lecture videos.

Downloads the video, grabs frames and runs OCR on them. A Spring Boot API with Python scripts underneath.

`Java` `Spring Boot` `Python` `Tesseract`
